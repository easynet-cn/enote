## 25. 待办管理

ENote 内置待办（Todo）功能，用于管理日常任务。待办支持清单归类、优先级、截止日期、提醒、重复、子任务、关联笔记与标签，并配备四象限视图、统计概览和番茄钟，帮助高效推进任务。

### 25.1 打开待办

打开待办视图有以下几种方式：

- **侧边栏：** 点击侧边栏"待办"下的任一视图（全部 / 今天 / 计划 / 已过期 / 四象限）或清单、标签。
- **底部工具栏：** 点击侧边栏底部工具栏中的待办图标按钮，直接打开待办的"全部"视图。
- **返回笔记：** 在待办视图中点击右上角的关闭按钮，返回笔记视图。

进入待办视图后，界面布局为：

- **左侧（原笔记列表面板）：** 待办列表与快速新建输入框。
- **右侧（原编辑器面板）：** 选中待办的详情。

### 25.2 新建待办

在待办列表顶部的输入框中输入待办标题，按 Enter 键即可快速创建。

需要设置更多属性时，可在详情面板中点击"编辑待办"，在弹出的编辑对话框中配置：

- **标题：** 必填，不能为空。
- **备注：** 待办的详细说明。
- **优先级：** 无 / 低 / 中 / 高。
- **截止日期：** 无截止日期，或指定具体日期。到期当天显示"今天到期"，逾期显示"已过期"。
- **提醒时间：** 为待办设置提醒时刻。
- **重复：** 不重复 / 每天 / 每周 / 每月 / 每年，可设置"每 N 个周期"以及"重复截止日"。
- **清单：** 将待办归入某个清单，未归类时归入"未归类"。
- **标签：** 为待办关联一个或多个标签。
- **关联笔记：** 可将待办关联到一篇笔记，便于从任务跳转到笔记详情；也可选择"不关联"。
- **子任务：** 为待办添加子任务，列表中显示子任务数量。

### 25.3 编辑待办

在左侧列表选中待办后，右侧详情面板显示其内容；点击"编辑待办"打开编辑对话框，可修改上述全部属性并保存。

### 25.4 完成与删除待办

- **完成：** 点击待办前的复选框将其标记为已完成，再次点击可取消完成。
- **删除：** 删除待办后进入待办回收站，可在回收站中恢复或彻底删除。

### 25.5 清单管理

清单用于对待办分组归类：

- **新建清单：** 点击"清单"区域标题旁的"新建清单"按钮，输入清单名称后创建。
- **切换清单：** 在侧边栏的清单列表中点击某个清单，仅显示该清单下的待办；点击"未归类"显示未归入任何清单的待办。
- **删除清单：** 删除清单时，清单下的待办不会被删除，而是转为"未归类"。

### 25.6 视图筛选

侧边栏提供多种预设视图，快速聚焦不同范围的任务：

| 视图 | 说明 |
|------|------|
| 全部 | 显示所有未完成与已完成的待办 |
| 今天 | 显示截止日期为今天的待办 |
| 计划 | 显示已设置截止日期的待办 |
| 已过期 | 显示已超过截止日期且未完成的待办 |
| 四象限 | 按重要 / 紧急程度分四象限展示 |
| 回收站 | 显示已删除的待办 |

### 25.7 四象限视图

四象限视图按"紧急"和"重要"两个维度自动归类待办：

- **紧急：** 未完成且截止日期为今天或之前。
- **重要：** 优先级为"高"。

据此划分为四个象限：

- **重要且紧急**（优先级高且已到期或今日到期）
- **重要不紧急**（优先级高但尚未到期）
- **紧急不重要**（优先级非高但已到期或今日到期）
- **不重要不紧急**（优先级非高且尚未到期）

### 25.8 搜索与显示已完成

- **搜索：** 在待办列表的搜索框中输入关键词，按标题筛选待办。
- **显示已完成：** 通过"显示已完成"开关控制是否在列表中展示已完成的待办。

### 25.9 批量操作

点击列表右上角的"批量"按钮进入批量模式，可一次处理多个待办：

- **全选：** 选中当前列表中的全部待办。
- **标记完成：** 将选中的待办批量标记为已完成。
- **移动到清单：** 将选中的待办批量移动到指定清单。
- **删除：** 批量删除选中的待办。
- **退出批量：** 退出批量模式并清空选择。

批量模式下会实时显示"已选 N 项"。

### 25.10 统计概览

待办列表上方显示统计信息，便于掌握整体进度：

- 总数、未完成、已完成
- 今日到期、已过期
- 完成率（百分比）

### 25.11 番茄钟

待办视图内置番茄钟，辅助专注工作：

- **开始专注 / 暂停：** 默认一个专注周期为 25 分钟，可随时暂停。
- **重置：** 将计时器恢复到 25 分钟。
- 计时结束时弹出提示"专注时间结束，休息一下"。

### 25.12 回收站

删除的待办进入回收站，可在此管理：

- **恢复：** 将待办恢复到原清单。
- **彻底删除：** 永久删除该待办，不可恢复。
- **清空回收站：** 一次性永久删除回收站中的全部待办，此操作不可恢复。
